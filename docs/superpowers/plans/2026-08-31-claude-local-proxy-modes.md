# Claude Local Proxy Modes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Claude Code support through a selectable local proxy mode while preserving the existing Codex and video services.

**Architecture:** One public proxy endpoint (`8848`) selects either the existing Codex adapter or a new Anthropic Messages adapter. Both forward to llama-server on `8846`; the UI persists a numeric mode and `claude-local` reads only the local Qwen record from CC Switch.

**Tech Stack:** Python standard library, llama.cpp HTTP API, vanilla HTML/JavaScript generated by `gen.py`, unittest/pytest.

**Spec:** `openspec/changes/claude-local-proxy-modes/design.md`

## Global Constraints

- Public proxy binds only to `127.0.0.1:8848`.
- `8850` remains the ComfyUI video port.
- `proxy_mode` values are exactly `0`, `1`, and `2`.
- Existing `codex_proxy` preferences remain readable.
- No changes to existing Codex protocol behavior.
