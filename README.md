# ImageVideoStudio · 生图/生视频小助手

一个**打开网页就能用**的本地 AI 画图/出视频操作台。不用记命令、不用写代码,选模型 → 填提示词 → 出图,全程点点点。

底层用的是开源的 [ComfyUI](https://github.com/comfyanonymous/ComfyUI),本项目是一个**对新手友好的中文网页外壳** + 一键安装脚本。

> 目前支持 **macOS**(Apple Silicon / Intel)。Windows 支持在 `windows` 分支开发中。

---

## ✨ 能干嘛

**图片生成**(主功能,网页操作):
- 🖼️ **文生图** — 输入一句话出图
- 🎨 **以图生图** — 给一张参考图,保持画风改内容
- 🩹 **局部重绘** — 在图上涂抹一块,只重画那块(换脸/换衣服)
- 🔍 **放大变清晰** — 小图重绘放大
- 🦴 **姿势控制** — 给张骨架图/线稿,人物照着摆姿势(需放 ControlNet 辅助模型)

**视频生成**:网页一键跳到 ComfyUI 操作(参数更全)。

其它贴心功能:一次最多 10 张、每张单独设尺寸/提示词、实时进度条(排队/生成中分开显示)、可选给结果打马赛克。

## 🚀 快速开始(Mac)

只需 4 步,全程在终端复制粘贴:

```bash
# 0. 进入项目目录
cd ImageVideoStudio

# 1. 安装 ComfyUI(自动:官网→国内镜像→失败则提示你手动)
./install.sh

# 2. 下载一个图片模型,放进 models/image/
#    不知道下哪个?打开 models/image/README.html,里面有推荐和下载链接

# 3. 启动生图服务
./start.sh

# 4. 打开操作台(会自动开浏览器)
python3 gen.py
```

然后浏览器访问 **http://127.0.0.1:8860** 就能用了。

## 📁 模型放哪(重要)

本项目**不打包、不自动下载模型**(模型动辄几个 GB,且有各自的授权协议)。你只需把模型文件拖进对应文件夹,网页会自动检测到:

```
models/
├── image/              ← 图片模型(.safetensors),看里面 README.html 有推荐+下载链接
│   ├── controlnet/     ← 图片辅助模型:姿势控制的 ControlNet(可选)
│   └── README.html
└── video/              ← 视频模型,看里面 README.html
```

每个文件夹里都有一个 **中文 README.html**,写明了该放什么、推荐哪个、去哪下载。

> 缺模型时生成会报错,网页会把错误显示出来 —— 九成是缺模型或辅助模型,照 README.html 补上即可。

## ⚙️ 它是怎么工作的

```
你的浏览器  →  gen.py(网页操作台, 端口8860)  →  ComfyUI(真正画图, 端口8849)  →   models/ 里的模型
```

- `gen.py` — 网页操作台,**只用 Python3 标准库,零依赖**
- `install.sh` — 一键装 ComfyUI(官网 git → 国内镜像 → 手动指定)
- `start.sh` — 生成模型路径映射 + 启动 ComfyUI
- `config.json` — 首次运行自动生成(端口、ComfyUI 路径)

首次启动时网页会**自动检测环境**:没装 ComfyUI 会提示你装;没放模型会告诉你放哪。

## 🛠️ 常见问题

**Q: 网页提示"还没检测到 ComfyUI"?**
运行 `./install.sh`。已经装过的话,把路径填进 `config.json` 的 `comfy_dir`。

**Q: 生成报错 / 不出图?**
基本是缺模型。确认 `models/image/` 里有 .safetensors 模型;要用姿势控制还得在 `models/image/controlnet/` 放 ControlNet。

**Q: 停止生图服务?**
`./start.sh stop`

**Q: 内存要多大?**
图片:建议 ≥16GB。视频:建议 ≥32GB。内存不够就关掉其他大软件、选小模型。
