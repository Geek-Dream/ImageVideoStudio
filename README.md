# 🎨🎬 ImageVideoStudio · 本地 AI 创作工作台

**打开网页就能用的本地 AI 一体机**：画图 🖼️、出视频 🎬、本地大模型聊天 💬、语音合成 🎙️、生成漫画 📚——全程点点点，不用记命令、不用写代码。

底层由 [ComfyUI](https://github.com/comfyanonymous/ComfyUI)（画图/视频）和 llama.cpp（语言模型）驱动，本项目是一个**对新手友好的中文网页外壳** + 一键安装/启停脚本。

> 目前支持 **macOS**（Apple Silicon / Intel）。模型文件体积大且有各自授权，**本仓库不含任何模型、提示词与生成产物**，请自行下载放置。

---

## ✨ 能干嘛

| 功能 | 说明 |
|---|---|
| 🖼️ **文生图** | 输入一句话出图，支持 SDXL / Flux / SD3.5 等多种架构 |
| 🎨 **以图生图** | 给一张参考图，保持画风改内容 |
| 🩹 **局部重绘** | 涂抹一块只重画那块（换脸/换衣服） |
| 🔍 **高清放大** | 小图重绘变大图 |
| 🦴 **姿势控制** | 给骨架图/线稿，人物照着摆姿势（需 ControlNet 模型） |
| 🎬 **视频生成** | 网页一键进入 ComfyUI 视频工作流 |
| 💬 **本地大模型** | 内置语言服务：网页里写故事、润色提示词；还支持 Claude Code / Codex 等客户端直连本地模型 |
| 🎙️ **语音合成** | 本地 TTS，可配自己的音色参考 |
| 📚 **漫画引擎** | 分镜、对话气泡、角色锁脸一条龙 |
| 🧪 **图片/视频测试场** | 批量排队对比不同模型和参数，一次看懂哪个效果最好 |
| 📊 **菜单栏状态** | macOS 菜单栏实时显示本地模型在忙什么 |

## 🚀 快速开始（Mac）

只需 3 步，终端里复制粘贴：

```bash
# 0. 进入项目目录
cd ImageVideoStudio

# 1. 安装 ComfyUI（自动：官网 → 国内镜像 → 失败则提示手动；装过会自动找到）
./install.sh

# 2. 下载模型放进 models/（每个子文件夹里有中文 README.html，写了推荐和下载链接）

# 3. 一条命令：检查环境 → 启动服务 → 自动打开网页
./start.sh
```

浏览器自动打开 **http://127.0.0.1:8860**。
停止服务：`./start.sh stop`

## 📁 模型放哪（重要）

```
models/
├── image/          ← 图片模型（.safetensors / .gguf），子目录含 controlnet / diffusion / encoder / vae 等
├── video/          ← 视频模型（可放实体文件，也可放指向外部目录的软链）
├── llm/            ← 语言模型（.gguf，网页的"语言"服务用）
└── tts/            ← 语音模型 + 音色参考
```

每个文件夹里有 **中文 README.html**，写明了该放什么、推荐哪个、去哪下载。
缺模型时网页会把错误显示出来——九成是缺模型或辅助模型，照 README.html 补上即可。

## ⚙️ 它是怎么工作的

```
你的浏览器
   ↓
gen.py（网页操作台，端口 8860，纯 Python 标准库零依赖）
   ↓
├── ComfyUI（画图/视频，端口 8849/8850）
└── llm.py（本地语言服务，端口 8848，经 codex_proxy / claude_proxy / harmony_proxy
    协议代理，可服务网页和 Codex / Claude Code 客户端）
```

- `start.sh` — 环境检查 + 三类服务（生图/生视频/语言）统一启停，内存互斥，启一个会先停另一个
- `svc.py` — 服务状态探测（PID + 端口双保险）
- `mac_status_item.py` — 菜单栏实时状态
- `install.sh` — 一键装 ComfyUI

## 🛠️ 常见问题

**Q：网页提示"还没检测到 ComfyUI"？**
运行 `./install.sh`。装过的话，把路径填进 `config.json` 的 `comfy_dir`。

**Q：生成报错 / 不出图？**
基本是缺模型。看对应模型目录里的 README.html 补齐。

**Q：内存要多大？**
图片：建议 ≥16GB。视频/大语言模型：建议 ≥32GB。
