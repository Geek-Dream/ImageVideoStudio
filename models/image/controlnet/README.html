🦴 这个文件夹放「图片辅助模型(ControlNet)」

这是可选的。只有你想用「姿势控制」(给一张骨架图/线稿,让人物照着摆姿势)这个玩法时,才需要在这里放一个 ControlNet 模型。
普通文生图、图生图、局部重绘、放大都不需要它。放好之后,网页的玩法下拉里才会出现「姿势控制」。

推荐(一个文件搞定所有控制类型)

controlnet-union-sdxl-1.0(推荐)
一个文件同时支持 骨架openpose / 涂鸦scribble / 深度depth / 线稿canny,约 2.5GB,配 SDXL 图片模型用。
官方: diffusion_pytorch_model.safetensors
国内镜像: hf-mirror 同款
下载后建议改名为 controlnet-union-sdxl-1.0.safetensors 再放进本文件夹。
⚠ 注意:ControlNet 和图片模型「架构要配套」。上面这个是 SDXL 用的,请搭配 SDXL 系列的图片模型(如推荐的 SDXL Base / Animagine)。
