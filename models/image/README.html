🖼️ 这个文件夹放「图片模型」

把下载好的 单个 .safetensors 模型文件直接放进本文件夹(models/image/),刷新网页就能选到它。
支持 .safetensors / .ckpt。本项目用 ComfyUI 的 CheckpointLoaderSimple 加载,适合 SDXL / SD1.5 等单文件大模型。

推荐新手模型(安全、能直接出好图)

① SDXL Base 1.0(官方通用,推荐第一个下)
Stability 官方底模,人物/风景/物品都行,约 6.9GB。
官方: sd_xl_base_1.0.safetensors
国内镜像: hf-mirror 同款
② RealVisXL(写实照片风)
想要真人照片感选它。
页面: huggingface.co/SG161222/RealVisXL_V4.0(点 Files 下 .safetensors)
③ Animagine XL(二次元动漫风)
想要动漫/二次元选它。
页面: huggingface.co/cagliostrolab/animagine-xl-3.1

怎么下载

点上面的链接会直接下载,或复制链接用命令(任选其一):

curl -L -o 模型名.safetensors "下载链接"
下载完把文件移动进本文件夹即可。

💡 提示:可以放好几个模型,网页里随便切换。姿势控制等高级玩法需要的辅助模型,请放进旁边的 controlnet/ 文件夹(看那里的说明)。
