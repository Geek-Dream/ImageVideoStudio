# macOS Native LLM Status Item

## Why

语言模型运行状态目前只在浏览器控制台中可见。用户关闭浏览器后，仍需要在 macOS 菜单栏中知道模型是否正在加载、读取输入或生成回复，以及快速查看当前进度。

## What Changes

- 在 macOS 上增加独立于浏览器控制台的原生菜单栏状态项，交由 macOS 菜单栏管理显示位置。
- 项目启动时检测当前操作系统；本 change 只启用 macOS 实现，Windows 保持现有行为，不新增 Windows 组件。
- 菜单栏状态项根据语言模型状态显示当前阶段：模型加载、读取输入及百分比、生成回复及已生成 token 数、空闲或异常。
- 独立状态进程持续监测后台模型；检测到语言模型运行时创建菜单栏项，模型停止后移除菜单栏项。状态项在浏览器关闭后仍继续工作。
- 状态数据复用现有语言模型状态接口/日志解析，不改变模型推理协议或浏览器聊天界面。

## Non-goals

- 不实现 Windows 任务栏托盘或其他 Windows 原生 UI。
- 不要求浏览器保持打开，也不把状态栏做成网页元素。
- 不增加模型控制操作（启动、暂停、停止等）；首版只读展示状态。
